# 0.4.0
Bounded-window transcription and resumable jobs for the native C++17/whisper.cpp CLI. Docker remains optional packaging of the same executable; there is no Python runtime or model weight in either archive.

## Highlights
- Decode audio incrementally and recognize bounded windows (120 seconds by default), retaining unfinished tails and checkpointing committed segments. Entirely digital-silent windows skip inference.
- Resume interrupted jobs, including partially published output sets, with source/model/settings verification. CPU thread counts and equivalent model paths may change without losing progress.
- Produce readable TXT paragraphs, normalized SRT, escaped WebVTT and JSON with per-segment language metadata. `--format all` includes all four formats.
- Preserve container-relative subtitle timing, codec gapless trimming and ordinary packet gaps. Handle format changes and recording-clock drift; `--timestamp-gaps auto|preserve` controls large forward transport gaps.
- Recover damaged audio with `--decode-errors tolerant|strict` and a configurable 30-second input-duration budget, plus an independent no-progress guard. Errors explain restart and repair options.
- Select resource-aware CPU threads and portable CPU plugins, including non-AVX2 x86_64. Add resumable model downloads, quantized turbo models, quieter logs, progress/ETA and richer `doctor` diagnostics.

## Upgrade Notes
JSON changes from schema 1 in 0.3.0 to schema 2. TXT uses paragraphs by default; `--text-layout single-line` retains the old layout. An existing three-format output set is not a complete four-format `all` result.

Checkpoints use schema 3, decoding policy 1, audio timeline 3 and chunking 4, including both decode-error settings in their identity. Older incompatible development checkpoints are not migrated. Finish them with the original binary, use a new output destination, or explicitly restart with `--overwrite` without `--resume`. Published 0.3.0 has no resumable partial jobs. Completed transcripts and model files are not changed by upgrading.

Windowing bounds recording-length-dependent audio buffers, not total model RAM/VRAM. Smaller windows can increase repeated tail recognition. See [resume semantics](https://github.com/egor-fedorov/whisper-transcribator/blob/v0.4.0/docs/resume.md) and [migration](https://github.com/egor-fedorov/whisper-transcribator/blob/v0.4.0/docs/migration.md).

## Distribution And Verification
CPU and CUDA archives target Linux x86_64 / Ubuntu 22.04+ (glibc 2.35+). Keep `bin/`, `lib/` and `share/` together. Bundles contain FFmpeg/inference libraries, TLS trust, dependency sources, licenses and checksums, but no weights, glibc or NVIDIA host driver. CUDA needs a compatible driver; compiled architectures are SM75/80/86/89/90.

Both archives are built by GitHub-hosted Actions runners in pinned Ubuntu 22.04 Docker build environments (CUDA 12.8.1 for the CUDA flavor), from the exact release commit. No self-hosted runner is used. Docker images can be built locally from the same bundles; this release does not publish registry images.

Release gates include GCC/Clang with warnings as errors, 29 CTest suites (28 under ASan/UBSan), FFmpeg 5.1 compatibility, formatting/shell checks, all-history secret scanning, archive/source/checksum verification, clean-Ubuntu CPU/Docker smoke and non-AVX2 QEMU inference. CUDA hardware smoke uses the exact release archive on a local RTX 4060 Ti (SM89); other compiled GPU architectures are not hardware-certified. Inference checks use only short public JFK fixtures, never full lectures or private media.

## Known Limitations
- No parallel file jobs, word timestamps, diarization or automatic lecture summaries. Model verification still hashes full weights; small lock files intentionally remain.
- A window without a safe segment boundary can still use a warned hard-cut fallback ([#17](https://github.com/egor-fedorov/whisper-transcribator/issues/17)).
- Inference without progress callbacks may appear idle; progress after a timestamp correction omits an unreliable ETA ([#18](https://github.com/egor-fedorov/whisper-transcribator/issues/18), [#27](https://github.com/egor-fedorov/whisper-transcribator/issues/27)).
- A truncated recording can finish successfully using only available audio without a reliable missing-tail warning. Decoder diagnostics remain in stderr, not persisted in transcript JSON ([#25](https://github.com/egor-fedorov/whisper-transcribator/issues/25)).
- Tolerant recovery skips rejected data; it cannot repair lost speech. Garbage decoded frames with unusable conversion parameters can still fail at resampler initialization ([#26](https://github.com/egor-fedorov/whisper-transcribator/issues/26)).
- Mixed speech/silence windows still use normal inference; disabling VAD can produce silence hallucinations. Minor FFmpeg log-fragment issues remain ([#27](https://github.com/egor-fedorov/whisper-transcribator/issues/27)).
