# 0.3.0
The first native release: one C++17/whisper.cpp CLI with optional Docker. Python remains only in the frozen `v0.2.0` history, not a maintained backend. Linux x86_64 CPU/CUDA archives include shared libraries, license notices and dependency sources, but no model weights. Docker images are built locally; there is no image-registry publication in this release.

## Artifact Provenance
- CPU: built on a GitHub-hosted `ubuntu-24.04` runner inside an Ubuntu 22.04 Docker build environment; downloaded from the [package job](https://github.com/egor-fedorov/whisper-transcribator/actions/runs/36261560860/job/108458252457).
- CUDA: built locally in Docker using CUDA 12.8.1 / Ubuntu 22.04; previously compiled dependencies were reused when refreshing the final bundle. No self-hosted runner was used.
- Packaged project sources were compared byte-for-byte with the release commit before publication. The final commit also passed CI; the CPU asset originated from the earlier PR run linked above, not that final run.

## Verification
- GCC and Clang builds passed all three CTest suites: 29 core checks, audio decoding/resampling tests and CLI integration tests. Wrapper ASan/UBSan passed.
- clang-format 18, ShellCheck, actionlint and all-history secret scanning passed.
- CPU and CUDA archives and images passed offline inference on the public 11-second JFK fixture with tiny weights. No full lectures were used.
- Archive smoke checks covered VAD on/off, TXT/SRT/JSON, sequential jobs, numbered maps, skip-existing, failure continuation and SIGTERM cleanup.
- Both archives ran in clean Ubuntu 22.04 with no Python or system FFmpeg. CPU archive/image execution also passed as a non-root user.
- CUDA inference used RTX 4060 Ti (SM89). SM75/80/86/89/90 were compiled; the other GPU architectures have not been tested on hardware.
- Archive checksums, bundled dependencies, license notices and source packages were checked. glibc and the NVIDIA host driver are not bundled.
- The [first remote CI run](https://github.com/egor-fedorov/whisper-transcribator/actions/runs/36260566858) passed GCC, Clang/sanitizers, CPU archive/image smoke tests and secret scanning. The manual CUDA job was skipped; GPU verification was local.

## Limitations
Archives require Ubuntu 22.04+ (glibc 2.35+) and a Haswell-class AVX2/FMA/F16C/BMI2 CPU. GPU container checks used explicitly exposed UVM devices and the default container UID; non-root GPU execution depends on host device permissions. Audio still decodes in full, so long-file memory use is not bounded. Jobs, batching, chunking and resume are not supported.

See the [installation instructions](https://github.com/egor-fedorov/whisper-transcribator#install) and [migration guide](https://github.com/egor-fedorov/whisper-transcribator/blob/main/docs/migration.md).
