# 0.3.0 Local Candidate

Verified locally on 2026-09-26. No tag, GitHub release or registry publication
has been made for this candidate. Python remains only in the frozen `v0.2.0`
history; the current product is one C++17/whisper.cpp CLI with optional Docker.

## Verification

- GCC and Clang builds passed all three CTest suites: 29 core checks, audio
  decoding/resampling tests and CLI integration tests. Wrapper ASan/UBSan passed.
- clang-format 18, ShellCheck, actionlint and all-history secret scanning passed.
- CPU and CUDA archives and images passed offline inference on the public
  11-second JFK fixture with tiny weights. No full lectures were used.
- Archive smoke checks covered VAD on/off, TXT/SRT/JSON, sequential jobs,
  numbered maps, skip-existing, failure continuation and SIGTERM cleanup.
- Both archives ran in clean Ubuntu 22.04 with no Python or system FFmpeg.
  CPU archive/image execution also passed as a non-root user.
- CUDA inference used RTX 4060 Ti (SM89). SM75/80/86/89/90 were compiled;
  the other GPU architectures have not been tested on hardware.
- Archive checksums, bundled dependencies, license notices and source packages
  were checked. glibc and the NVIDIA host driver are not bundled.

Artifacts remain local under `.build/artifacts/{cpu,cuda}/`. GPU container checks
used explicitly exposed UVM devices and the default container UID; non-root GPU
execution still depends on host device permissions. GitHub Actions are configured
but have not run remotely. Audio still decodes in full, so long-file memory use
is not bounded; chunking and resume are deferred. See the [migration guide](../migration.md)
and [release procedure](../releasing.md).
