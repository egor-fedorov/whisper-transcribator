# 0.2.0

Local release: 2026-09-26. No GitHub, PyPI or image-registry publication has been
performed. The supported product is the Python/faster-whisper CLI; Docker is an
optional distribution, not a requirement for running the installed Python package.
Native archives remain experimental and are not part of this supported release.

## Verification

- 59 unit tests passed on Python 3.10 and 3.13; local coverage was 86%.
- Ruff, ShellCheck, package builds/installations and dependency checks passed.
- CPU/CUDA Docker and native archive smoke tests used short public audio offline.
- Native wrapper sanitizer tests passed; this does not audit upstream libraries.
- Git history secret scanning found no leaks.
- GitHub Actions are configured but have not run on a remote repository.

The local wheel/sdist are in `dist/`. Build recipes and release gates are in
RELEASING.md. Models, private recordings and transcripts are not release assets.

## Migration

Use `transcribe`, `models list/download` and `doctor`; the original flat input
syntax still works. Shell scripts delegate discovery, jobs and skipping to Python.
Numbered mappings now use JSON; use a fresh prefix/directory for old TSV results.
Output protection remains enabled unless explicitly overridden.

Long files still decode in full in this release. Chunking/resume belongs to the
next development version, with an opt-in interface and separate validation.
